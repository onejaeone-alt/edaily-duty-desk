# EDAILY Duty Desk

이데일리 당직용 실시간 뉴스 모니터링 웹앱입니다.

## 동작 기준
- 첫 화면은 수집된 기사를 분야별 가중치 없이 최신 송고순으로 모두 표시
- 긴급/우선 추천 영역 없음
- 분야 버튼은 필터 용도로만 사용
- 통신3사(연합뉴스·뉴시스·뉴스1) 별도 보기
- 타사 단독 별도 보기
- 이데일리 유사 기사 제목 대조
- 30초 자동 갱신
- 처리 완료 상태는 브라우저 localStorage에 저장

## 수집
- 뉴시스: 공식 분야별 RSS
- 뉴스1: 공개 실시간 속보 페이지
- 연합뉴스: Google 뉴스 RSS 보완
- 타사 단독: Google 뉴스 RSS 검색
- 이데일리: Google 뉴스 RSS로 최근 기출고 제목 대조

## 실행
```bash
npm install
npm run dev
```

Next.js 프로젝트이므로 Vercel에서 저장소를 Import하면 됩니다.
